## SEO Guidelines

-   One H1 per page
-   1,500--2,000 words on core pages
-   60% service content / 40% location content
-   Internal links between services and locations
-   Optimized title tags, meta descriptions, image alt text
-   LocalBusiness, Service, FAQ, Breadcrumb schema

## Elementor Tips

-   Use Flexbox Containers.
-   Create global colors and fonts.
-   Compress images to WebP.
-   Reuse templates for CTAs and service cards.
-   Keep heading hierarchy logical.
